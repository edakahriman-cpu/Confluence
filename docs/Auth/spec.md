Backend Auth isterler
1- Kullanıcı adı ve şifresiyle giriş yapılmalıdır. Şifre en az 5 karakter içermelidir.
2- Auth güvenlik adımı için jwt token doğrulama adımı olmalıdır. 
Validasyon için class-validator kullan.
Auth için aşağıdaki servisler olmalıdır.
1- Login servisi
2- Register servisi
3- Şifremi unuttum servisi

Bu spec kapsamında sadece backend kurulumu olacaktır. Frontend için bir çalışma yapılmayacak.
